raya.netlify.app
◆ Boutique d'abayas · Alger

RAYA — Abaya Store

Conception et développement d'un site vitrine one-page pour une boutique d'abayas basée à Alger. Le site inclut une présentation de marque (hero, manifeste, savoir-faire), une galerie collection, un catalogue de modèles interactif où chaque photo révèle son prix au clic, un sélecteur de couleurs par modèle, ainsi qu'un formulaire de commande complet (nom, téléphone, wilaya, adresse, produit, couleur, quantité) qui enregistre automatiquement chaque commande dans un Google Sheet via Google Apps Script — sans backend ni base de données.

Stack : HTML, CSS, JavaScript vanilla, Google Apps Script. Fonctionnalités clés : design responsive, animations au scroll, formulaire de commande avec validation côté client, intégration Meta Pixel pour le suivi publicitaire. Déploiement : Netlify.

HTML CSS JavaScript vanilla Google Apps Script Netlify
greensteps.ooredoo.dz
◆ Ooredoo Algérie · Mémoire de fin de formation

GreenSteps

Une application mobile pensée pour engager la communauté Ooredoo autour de gestes écologiques concrets : économie d'eau, recyclage, réduction du plastique, plantation d'arbres. Chaque utilisateur suit sa progression et l'impact environnemental de ses actions au fil du temps.

Côté organisation, un dashboard d'administration permet aux équipes Ooredoo d'ajouter, modifier et suivre les défis proposés à la communauté.

Application mobile Dashboard admin Sensibilisation environnementale
sihatek.app
◆ Projet de fin d'études

Sihatek — gestion médicale

Une plateforme complète pour digitaliser le quotidien d'une clinique : les patients prennent rendez-vous en ligne, les médecins gèrent ordonnances et dossiers médicaux, et l'administrateur pilote utilisateurs, rendez-vous et prescriptions depuis un tableau de bord unique.

L'ensemble est accessible via le web et une application mobile Flutter, synchronisées en temps réel grâce à une API centralisée développée avec Laravel.

Laravel API Flutter Web Base de données centralisée
